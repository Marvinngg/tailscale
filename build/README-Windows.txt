Antigravity Tailscale - Windows Installation
=============================================

Steps:
1. Edit connect.conf, replace REPLACE_WITH_YOUR_AUTH_KEY with your auth key
2. Double-click setup.exe (will auto-request admin permission)
3. Wait for installation to complete
4. Done - you're connected

If setup.exe cannot find tailscale-install.exe (official installer),
download it first from: https://pkgs.tailscale.com/stable/tailscale-setup-latest.exe
and rename to tailscale-install.exe, place in same folder as setup.exe.

Uninstall: double-click uninstall.bat (as admin)
